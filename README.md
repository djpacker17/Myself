# Leo | Portafolio

Portafolio de Leo: desarrollador web, aplicaciones y scripts de Roblox. Disponible en español e inglés.

Ver en línea: https://djpacker17.github.io/Myself/

## Archivos

- `index.html`: la página completa (estilos y scripts incluidos).
- `404.html`: página para enlaces que no existen.
- `media/`: avatar, capturas de Zypuc, intro en video e imagen de vista previa (`og.png`).

Para cambiar los enlaces de Fiverr o GitHub, o activar el contador de visitas, edita el bloque `CONFIG` al inicio del script en `index.html`.
